# Progiant millwork landing page

The deployable static site is in `github-pages/`. Push the repository to GitHub with the default branch named `main`, then set **Settings → Pages → Build and deployment → Source** to **GitHub Actions**. The included workflow publishes every push to `main`.

Form submissions are sent through FormSubmit to `info@71systems.com`. The first submission triggers an activation email; approve it once before sending campaign traffic. After activation, test a complete submission and confirm receipt.
